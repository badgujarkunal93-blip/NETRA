# SIH 26189 — Stitch UI Prompts (Official Government Portal Theme) Matches the reference design: navy-blue + white + gold/amber, official/authoritative, government-portal credibility — not noir, not generic tech-SaaS. **Shared style guide — repeat this block's key points if any screen drifts:** - Primary background: deep navy blue (#0B1E3D–#0F2547 range) for header, nav, and hero/dashboard sections - Secondary background: clean white / very light grey (#F5F6F8) for content and data-table sections - Accent color: warm gold/amber (#D4A017–#E0A93A range) — used for primary CTAs, active states, highlight numbers, key stat figures - Alert/danger color: muted red (#C0392B–#D64541) used sparingly — only for emergency/high-severity indicators, never decorative - Text: white/off-white on navy backgrounds, dark navy/charcoal (#1A1A1A–#1F2937) on white backgrounds - Typography: bold, slightly condensed sans-serif for headings (uppercase tracking on nav labels and section titles), clean readable sans-serif (Inter/Roboto-style) for body text — no script/decorative fonts, no monospace/typewriter styling - Iconography: simple, clean line icons (shield, fingerprint, database, network, document) — official and minimal, not illustrative - Overall tone: an authoritative, credible government/law-enforcement portal — think official department website crossed with a professional intelligence command console.
